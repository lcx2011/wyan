## 三、已完成的修复

### P0：关键业务路径

1. **离线同步队列**
   - 覆盖 250ms 防抖、成功出队、失败保留与重试、并发 flush 复用、同步期间新写入不被误删、暂停开关。
   - `syncQueue.ts` 语句覆盖率由约 23% 提升至 **97.82%**，分支覆盖率 **96.29%**。
   - 增加显式启停入口，使测试环境默认不访问网络，同时可以在单元测试内受控验证真实同步逻辑；生产环境仍默认启用。

2. **在线古诗文 API**
   - 覆盖搜索请求参数、成功响应、异常响应、HTTP 错误、详情获取、ID URL 编码、本地篇目转换和 8 秒超时中止。
   - `gushiwen.ts` 语句覆盖率提升至 **100%**。

3. **在线篇目存档与迁移**
   - 覆盖删除、查询、迁移通知关闭、内容版本变化后的进度迁移，以及原子写入失败时不更新内存状态。
   - `passageStore.ts` 语句覆盖率由约 45% 提升至 **92.5%**，分支覆盖率 **78.57%**。

4. **远程复习 API**
   - 覆盖创建/恢复会话、提交带幂等 operationId 的结果、服务不可用时回退本地模式、禁用远程 API。
   - `review.ts` 语句覆盖率由约 18% 提升至 **89.47%**。

### P1：页面与生命周期

1. **主页**：新增待复习红点显示/隐藏、复习入口和新学入口导航测试；`HomePage.tsx` 语句与函数覆盖率均为 **100%**。
2. **搜索页**：新增在线结果渲染、添加篇目成功并跳转、在线失败回退、空结果和存储配额失败测试。
3. **页面暂停**：新增隐藏/显示、失焦/聚焦、checkpoint、回调更新、禁用和卸载清理测试；`usePagePause.ts` 语句、分支、函数覆盖率均为 **100%**。
4. **组件测试稳定性**：将首页、复习页、Boss/报告页测试改为静态加载并显式重置 store，消除覆盖率并发运行时的超时和失败后 DOM 污染。

### P2：存储、日期与服务端异常

1. **日期边界**：覆盖跨月、跨年，以及 UTC 时间戳与本地日历日期的差异。
2. **存储异常**：覆盖未来 schema、迁移失败、序列化失败、QuotaExceeded、存储不可用、旧存储 helper 的损坏数据清理；`utils/storage.ts` 语句覆盖率提升至 **92.2%**，分支覆盖率 **88.57%**。
3. **服务端**：覆盖非法 namespace、缺少 payload、无效/陈旧 attempt、不存在或未完成会话、已完成会话、防御性存档结构、SPA fallback 与 API 404。
   - `server/app.ts`：语句 **98.43%**、分支 **88.88%**。
   - `server/db.ts`：语句 **96.66%**、分支 **90.52%**。
4. **质量门槛**：新增 `npm run test:coverage`，并在 Vitest 配置中设置覆盖率阈值，低于门槛时命令直接失败。
