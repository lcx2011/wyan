# 学习流程优化方案（科学背诵版 · 单日会话）

> 版本：v2.1 ｜ 日期：2026-08-11 ｜ 状态：待评审
> v2.1 调整：按评审意见，**不做天级拆分**（跨天巩固属于复习系统，由 1/3/7 覆盖）；所有优化**压缩到一天内的单次学习会话**。间隔思想保留，但间隔尺度从"天"降到"分钟"。
> 关联：PRD.md（F01–F08）、ARCHITECTURE.md（D1–D5）

## 0. 核心洞察

**"背过了"是假象：学生用短时记忆通关了三连闯关。**

现状里，一张卡从"展示 → 挖空 → 首字 → 整卡盲打 → 两卡衔接 → 整段成篇 → Boss"在 **10–30 分钟内一气呵成**，全程由短时记忆支撑——刚看过的字还在脑子里，自然"打得出"，第二天全忘。

科学依据（都适用于**一天内**的分钟级尺度）：

- **间隔效应**：同一内容连续提取，靠的是工作记忆；留出间隔、让记忆先开始消退再提取，长期记忆才真正建立。研究显示**哪怕 10 分钟间隔也显著优于零间隔**；
- **遗忘曲线**：记忆 20 分钟内衰减最快——"学完马上测"与"隔 10 分钟测"测的已不是同一种记忆；
- **交错练习**：交替做不同内容（复习旧篇、学下一卡）优于集中练同一内容，且交错本身天然产生间隔。

结论：**不加关卡、不跨天，只在一天内的环节之间插入分钟级间隔，让每一次滚雪球/Boss 都成为"记忆稍微消退后的提取"**。跨天巩固（1 天/3 天/7 天）由复习系统承担。

## 1. 问题诊断

### 1.1 现状（问题所在）

```
单次会话  展示 → 三连(挖空→首字→盲打) → 滚雪球(衔接→成篇) → Boss 验收   ← 连续做完，零间隔
之后     次日复习（错题一次，答对即毕业）
```

- 环节间零间隔：三连三关连续、三连完马上滚雪球、滚雪球完马上 Boss——**每个环节测的都是刚喂进短时记忆的内容**；
- 复习一次即毕业：跨天的巩固缺失，错题复习一次就放行。

### 1.2 具体机制问题

| # | 问题 | 位置 | 后果 |
|---|---|---|---|
| A1 | 盲打错一全重（整单元重置） | `TypingUnitRunner.onMiss` → `session.reset()` | 长单元（30–120 字）反复重打，挫败卡死 |
| A2 | 环节间零间隔，集中练习 | 三连→滚雪球→Boss 连续做 | 短时记忆通关，次日遗忘 |
| A3 | Boss 零错误才通关 | `attempt.ts: passed = wrongPositions.length===0` | 长文（出师表 600+ 字）不可达 |
| A4 | 复习一次即毕业 | `session.ts answerReview` | 跨天巩固缺失，无递增间隔 |
| A5 | 训练弱项不进复习 | 复习项只在 Boss 结算生成 | 三连/滚雪球错字漏复习 |

## 2. 科学背诵原理 → 设计原则

| 原理 | 内容 | 本方案对应设计 |
|---|---|---|
| 间隔效应 | 学习间隔开后记忆更牢（分钟级即有效） | **单日会话内环节间插入 10 分钟间隔锁** |
| 遗忘曲线 | 20 分钟内衰减最快 | 间隔默认 10 分钟，覆盖最关键消退窗口 |
| 提取练习 | 主动回忆比重读记忆效果好 | 盲打/滚雪球/Boss 都是提取，间隔化后检验真记忆 |
| 交错练习 | 交替做不同内容优于集中 | 间隔期间引导"复习旧篇/学下一卡"，天然交错 |
| 递增间隔 | 1 天 → 3 天 → 7 天 | **跨天部分全部归复习系统**（1/3/7，答对 3 次毕业） |

**设计原则**：① 一天内学完，不跨天；② 环节间留分钟级间隔，让记忆先消退再提取；③ 错字是信号，标红揭示不整单元作废；④ 路径线性，无跳过无降级。

## 3. 优化设计

### 3.1 核心改动：单日三段式 + 分钟级间隔锁

**改动点：`TripleChallengePage` / `SnowballPage` / `ExamPage` 入口 + `progressStore` 时间戳**

**一天内的三段式流程**：

```
段 A（即时学习）  展示 → 三连（挖空→首字→盲打）          完成写入 trainedAt
      │ 间隔锁 1（默认 10 分钟，可配置）
段 B（间隔后提取） 滚雪球（两卡衔接 → 整段成篇）          完成写入 snowballedAt
      │ 间隔锁 2（默认 10 分钟）
段 C（总提取验收） Boss 全文验收（分档通关）
之后              1/3/7 天复习循环（跨天，归复习系统）
```

- **段 A 内保持连续**：展示→挖空→首字→盲打是单卡脚手架（提示强度递减），连续做没问题，其定位就是"即时学习"；
- **段 B 是第一次间隔后提取**：10 分钟后盲打已经"有点忘了"，这时滚雪球还背得出，才是真会——这是整个方案的关键检验点；
- **段 C 是第二次间隔后提取**：Boss 前再过 10 分钟，检验巩固后的记忆。

**间隔锁实现**：

1. `progressStore` 增加 `trainedAt` / `snowballedAt`（Boss 完成后自动进入复习，无需 bossedAt）；
2. 间隔常量集中 `src/config/spacing.ts`：`MIN_SPACING_MS = 10 * 60 * 1000`（默认 10 分钟，家长可配 0–120 分钟）；
3. 解锁规则：滚雪球入口需 `now - trainedAt ≥ MIN_SPACING_MS`；Boss 入口需 `now - snowballedAt ≥ MIN_SPACING_MS`；跨天回来自动满足（间隔已过）；
4. **间隔期不做"干等"**——锁定页显示倒计时 + 三个去向按钮：① 复习旧篇目（交错）② 学另一卡/另一篇的三连（交错）③ 休息一下；间隔到期按钮自动点亮；
5. 首页显示每篇当前阶段：`学习中 → 间隔中（倒计时）→ 巩固中 → 间隔中 → 可验收`，红点给"现在能做的"（到期复习 > 到期滚雪球 > 到期 Boss > 新学）。

**为什么 10 分钟可行**：学生一天的学习时段通常 30–60 分钟，段 A（约 10 分钟）→ 间隔（可复习旧篇）→ 段 B（约 10 分钟）→ 间隔 → 段 C，全程一次会话内完成，间隔时间被"复习旧篇"填满而非空等。

### 3.2 盲打容错分级——错字标红揭示，不再整单元作废

**改动点：`TypingUnitRunner.tsx`、`domain/typing/engine.ts`、`domain/training/cardMachine.ts`**

| 档位 | 判定 | 行为 | 星级 |
|---|---|---|---|
| 完美 | 0 处错 | 直接通过 | ⭐⭐⭐ |
| 有错通过 | ≤2 处错（同一位置错第 2 次计入） | 错误位置标红并揭示正确字符，光标前进继续 | ⭐⭐ |
| 重置 | 第 3 处错（或同一位置错 2 次） | 整单元重置重打（不降级） | — |

- `engine.ts`：`handleInput` miss 时若未超阈值 → `revealed[cursor]=true` 并推进（新增 `allowRevealOnMiss` 选项，默认 false，盲打单元传入 true）；`wrongPositions/wrongCountByPosition` 字段已够，无需加 schema；
- `TypingUnitRunner.tsx`：`onMiss` 不再无条件 `session.reset()`，改为计数达阈值才 reset；
- 星级写入 progress，供报告展示。

### 3.3 Boss 分档验收 + 解锁放宽

**改动点：`ExamPage.tsx`、`domain/exam/attempt.ts`、`ReportPage.tsx`**

1. 解锁条件：所有卡盲打过 + ≥80% 段通过 + 间隔满足（3.1）；未学段虚线占位、报告标注；
2. 通关分档（`attempt.ts` 加 `grade`）：0 错 `perfect`（3 星）/ 1–5 错 `passed`（2 星）/ >5 错 `failed`（成绩入库、错句进复习）；
3. 报告页：错误按段/句聚合，"再挑战" + "回滚雪球巩固" + "立即复习错句"。

### 3.4 复习系统（跨天部分，保留并增强）

**改动点：`domain/review/session.ts`、`selection.ts`、`reviewStore`、`record.ts`**

1. **1/3/7 递增间隔**（Leitner 简化版）：`ReviewItem` 加 `box: 0|1|2`；答对升箱、答错回 0；box0 次日 / box1 隔 3 天 / box2 隔 7 天；**升到 box2 才毕业**（原"答对一次即毕业"改为按箱毕业）；
2. **训练弱项并入**：`recordTypingWeakness` 的三连/滚雪球错字生成复习项（补 `reviewStore` 生成路径），不再只依赖 Boss 结算；
3. **次日复核**：Boss 通过后次日生成一次整篇快速复核（巩固跨天记忆）。

## 4. 实施顺序与工作量

| 序 | 改动 | 涉及文件 | 工作量 | 优先级 |
|---|---|---|---|---|
| 1 | 单日三段式 + 分钟间隔锁（3.1） | progressStore / SnowballPage / ExamPage / 首页 | 1–1.5 天 | P0 |
| 2 | 盲打容错分级（3.2） | engine.ts / TypingUnitRunner / cardMachine | 0.5–1 天 | P0 |
| 3 | 复习 1/3/7 + 弱项并入 + 次日复核（3.4） | session.ts / selection.ts / reviewStore / record.ts | 1 天 | P1 |
| 4 | Boss 分档 + 解锁放宽（3.3） | ExamPage / attempt.ts / ReportPage | 0.5–1 天 | P1 |

P0（间隔锁 + 容错）落地即可解决"短时记忆通关"与"卡住"两大痛点，约 **1.5–2.5 天**。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 10 分钟间隔被学生嫌烦 | 间隔期提供"复习旧篇/学下一卡"入口（交错练习，科学上更优），不是空等；间隔可配置，家长可调短 |
| 学生刷新/改 localStorage 绕过间隔 | 间隔是"记忆巩固"引导而非安保机制；真实校验靠滚雪球/Boss 表现本身 |
| 一天内流程仍偏长（约 30–60 分钟） | 本就读物背诵一次学习时段；段 A 结束可自然"中场休息"，剩余段 B/C 下次回来自动满足间隔 |
| 容错分级让个别学生"混过"盲打 | 2 处阈值 + 同位重错即重置 + 星级可见；间隔后的滚雪球/Boss 会暴露混过者 |
| 复习项增多负担重 | `selectReviewGroup` 保持 ≤10 项 / ≤150 字上限 |

## 6. 待确认问题

1. **间隔时长**：默认 10 分钟是否合适？（可配置 0–120 分钟；0 = 关闭间隔，退回现状）
2. **间隔是否硬锁**：到点才能进滚雪球/Boss（推荐），还是软提示可提前进入？
3. **三连内部**：保持 挖空→首字→盲打 连续（推荐，段 A 定位即时学习），还是盲打也挪到间隔后？
4. **容错阈值 / Boss 分档**：盲打允许 2 处错、Boss 5 错内通关，是否可接受？

确认后按第 4 节实施；如想先验证"分钟间隔"效果，可先只做第 1 项（间隔锁）观察一周。
